# Stage gaps

Cards whose stage shows only the gallery photo under a heading, because no suitable picture was found
(licensed CC0 / CC BY / CC BY-SA, the card's own species, no people, nothing distressing). Each row
says what could fill the gap, so that every card ends up with something of its own to show.
Add rows as each heading is done; remove a row when its gap is filled.

Not published: `docs/` isn't in the site's allow-list (`scripts/build-site.mjs`).
